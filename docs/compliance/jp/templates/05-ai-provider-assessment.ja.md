## 3. PPC生成AI注意喚起（2023年6月2日）

- [ ] 個人情報を含む入力が、特定済み利用目的の必要範囲内である。
- [ ] 個人データが応答生成以外の目的で取り扱われない。
- [ ] 入力・出力を機械学習、モデル改善又は人手レビューに利用しない設定・契約を確認した。
- [ ] 設定をアカウント単位でなく契約・組織単位で強制できる。
- [ ] 規約・プライバシーポリシー変更の監視責任者と頻度を定めた。
- [ ] 削除・オプトアウトが既送信データ及びバックアップに及ぶか確認した。

証拠：［契約条項、設定画面、文書、確認日］

## 4. 外国提供と外的環境

- [ ] 提供先の法人所在地、処理国、保存国、サポート国、再移転先を確認した。
- [ ] 法第28条の経路（同意／相当措置／同等水準国／法第27条第1項例外）を特定した。
- [ ] 同意経路では規則第17条の情報を事前提供した。
- [ ] 相当措置経路では規則第18条の定期確認、支障時措置、提供停止及び本人への情報提供手順を設けた。
- [ ] 当該外国の制度、政府アクセス、データ主体の救済、域外移転及び開示禁止命令等を確認した。
- [ ] 保有個人データの安全管理措置として、公表すべき外的環境情報を整理した。

## 5. 技術・運用

- [ ] データ所在地を契約と設定で固定できる。
