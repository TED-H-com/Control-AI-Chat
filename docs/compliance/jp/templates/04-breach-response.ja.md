# 漏えい等対応手順と報告準備シート

> 本テンプレートは出発点であり、実際の取扱いに合わせて修正し、使用前に弁護士の確認を受けるものとする。

## 1. 初動

1. 発見者は直ちに［24時間窓口］へ連絡し、画面、日時、利用者、会話・メッセージ・ファイルID、提供先及び操作を保存する。
2. 対応責任者は、送信停止、アカウント・APIキー・セッションの無効化、ネットワーク隔離等、証拠を破壊しない封じ込めを行う。
3. 原本SQLite、アップロード、設定、資格情報リンク記録、監査ハッシュチェーン、CSV／JSON／NDJSON出力、サーバー・プロキシログ、設定済み SMTP リレーのメールログ、提供事業者側ログ及び契約を証拠として保全し、保存担当者、時刻、ハッシュ及び受渡しを記録する。
4. 法務、個人情報保護、情報セキュリティ、労務、広報及び事業責任者を招集し、PPCその他所管官庁、本人、委託元、保険者等への連絡を判断する。

## 2. 報告対象の判定

個人情報保護法施行規則第7条のいずれかのおそれがあるかを判定する。

- [ ] 要配慮個人情報を含む個人データ（高度な暗号化等の規則上の除外を要確認）
- [ ] 不正利用により財産的被害が生じるおそれがある個人データ
- [ ] 不正の目的をもって行われたおそれがある個人データの漏えい等
- [ ] 本人の数が1,000人を超える個人データの漏えい等

確定を待たず、「おそれ」で評価する。委託先で発生した場合の通知・代行報告、行政機関等、番号法、業法又は契約上の別報告も確認する。

## 3. 期限管理

| 対応 | 根拠・期限 | 内部期限 | 担当 |
|---|---|---|---|
| PPC速報 | 規則第8条第1項「速やかに」。通則ガイドラインの目安は事態を知った時から概ね3～5日以内 | ［知った時から○時間］ | ［記入］ |
| PPC確報 | 規則第8条第2項：知った日から30日以内。不正目的類型は60日以内 | ［記入］ | ［記入］ |
| 本人通知 | 規則第10条：状況に応じて速やかに | ［記入］ | ［記入］ |
| 委託元・契約先等 | 契約・業法の期限 | ［記入］ | ［記入］ |

## 4. PPC報告準備シート

規則第8条第1項の項目に沿って記入する。

| 項目 | 記録 |
|---|---|
| 概要 | ［発生日、発見日、知った日、態様、システム、提供先］ |
| 個人データの項目 | ［氏名、連絡先、要配慮情報、認証情報等］ |
| 本人の数 | ［確定／推計、算定方法、1,000人超のおそれ］ |
| 原因 | ［技術的・人的・組織的・委託先］ |
| 二次被害又はそのおそれ | ［なりすまし、財産被害、差別、秘密漏えい等］ |
| 本人への対応状況 | ［通知日、方法、未通知理由］ |
| 公表の実施状況 | ［公表日、URL、未公表理由］ |
| 再発防止策 | ［暫定・恒久、責任者、期限］ |
| その他参考事項 | ［外国提供先、回収・削除確認、暗号化、リーガルホールド等］ |

速報時に未判明の項目は「調査中」とし、判明後速やかに追完する。

## 5. 本人通知

本人通知には、規則第10条に従い、少なくとも概要、個人データの項目、原因、二次被害又はそのおそれ、その他本人の権利利益保護に必要な事項を含める。平易な言葉で、相談窓口、推奨する防御措置及び更新方法を示す。本人通知が困難で代替措置を採る場合は、その困難性と代替措置の実効性を記録する。

## 6. 収束

封じ込め、影響範囲、提供先での削除・利用停止、本人対応、報告、再発防止及び監査証拠を責任者が承認する。リーガルホールド解除後は、不要な調査コピーを消去する。検出器の見逃し又は誤検知を評価し、規程、教育、契約、設定及び演習へ反映する。
