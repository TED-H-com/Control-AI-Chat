## 個人情報保護法・施行令・施行規則

- [e-Gov法令検索「個人情報の保護に関する法律施行規則」](https://laws.e-gov.go.jp/law/428M60020000003) — 第7条の報告対象、第8条の報告時期・事項、第10条の本人通知、第17・18条の外国提供情報を確認。
- [PPC「個人情報の保護に関する法律についてのガイドライン（通則編）」](https://www.ppc.go.jp/personalinfo/legal/guidelines_tsusoku/) — 安全管理措置の区分、漏えい等報告の3～5日目安、委託先監督及び2026年6月一部改正を確認。
- [PPC「個人情報の保護に関する法律についてのガイドライン（外国にある第三者への提供編）」](https://www.ppc.go.jp/personalinfo/legal/guidelines_offshore/) — 法第28条の同意・相当措置・情報提供の解釈及び2025年12月一部改正を確認。
- [PPC「個人情報保護法ガイドラインQ&A」](https://www.ppc.go.jp/personalinfo/faq/APPI_QA/) — Q5-7、Q7-53・54、Q10-22以下、Q12-1以下の現行索引を確認。
- [PPC Q5-7「従業者のモニタリング」](https://www.ppc.go.jp/all_faq_index/faq1-q5-7/) — 目的、責任者・権限、事前ルール、適正運用確認及び周知の4点を確認。
- [PPC Q7-53「クラウドサービスと提供」](https://www.ppc.go.jp/all_faq_index/faq1-q7-53/) — 契約上の非取扱いと適切なアクセス制御という判断要素を確認。
- [PPC Q7-54「クラウド例外と監督」](https://www.ppc.go.jp/all_faq_index/faq1-q7-54/) — 法第25条の委託先監督が課されない場合も自らの安全管理措置が必要であることを確認。
- [PPC Q12-1「外国にある第三者への委託」](https://www.ppc.go.jp/all_faq_index/faq1-q12-1/) — 委託であっても法第28条第1項の検討が必要であることを確認。
- [PPC Q10-22「外的環境の把握」](https://www.ppc.go.jp/all_faq_index/faq1-q10-22/) — 外国委託等が外国における取扱いに当たることを確認。
- [PPC「漏えい等の対応」](https://www.ppc.go.jp/personalinfo/legal/leakAction/) — 報告・本人通知の公式案内及び報告フォームを確認。
- [PPC「漏えい等報告・本人への通知の義務化について」](https://www.ppc.go.jp/news/kaiseihou_feature/roueitouhoukoku_gimuka/) — 4類型、速報の概ね3～5日及び本人通知の公式要約を確認。
- [PPC Q&A Q202「健保組合における漏えい等対応」](https://www.ppc.go.jp/all_faq_index/faq4-q202/) — 規則第7・8条に基づく速報、30日・60日の確報期限を確認。
- [PPC「外国における個人情報の保護に関する制度等の調査」](https://www.ppc.go.jp/enforcement/infoprovision/laws/) — 外国制度の本人向け説明及び外的環境評価に用いる公式調査資料を確認。
- [PPC「我が国と同等の水準国の指定」](https://www.ppc.go.jp/files/pdf/200201_h31iinkaikokuji01.pdf) — EU加盟国及び英国に関する指定を確認。
