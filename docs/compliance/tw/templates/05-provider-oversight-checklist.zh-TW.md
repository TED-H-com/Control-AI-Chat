## AI 特有檢核

### 訓練與另行利用

- [ ] 契約明定不得以輸入、輸出或中繼資料訓練／微調共用模型。
- [ ] 人工審閱僅限服務必要、最少人員並留下紀錄；退出機制已測試。
- [ ] 濫用監控、安全偵測、評估與遙測的目的、欄位、期間及法律角色已明確。
- [ ] 模型改版、端點轉移或條款變更須事前通知並可停止使用。

### 保存、刪除與權利

- [ ] 零保存／最短保存設定及實際效果有文件證據；備份最晚刪除＿＿日。
- [ ] 可依個別請求查詢、更正、停止、刪除或提供合理協助。
- [ ] 供應商回覆請求的契約時限小於營運者法定 15／30 日期限。
- [ ] 終止後取得刪除／銷毀證明；例外法定保存有範圍與期限。

### 地點與跨境

- [ ] 處理、儲存、備援、支援及子處理者地點完整。
- [ ] 資料不會在未核准地區路由或供支援人員存取。
- [ ] 已完成 [國際傳輸評估](06-cross-border-transfer-assessment.zh-TW.md) 並查產業限制。

### 安全、韌性與查核

- [ ] 獨立安全驗證／查核的範圍、有效期、例外與補救已審閱；證書本身不是充分保證。
- [ ] 有事件演練、營運持續、復原目標、容量與集中風險方案。
- [ ] 營運者／主管機關／指定人查核權符合適用產業規則。
- [ ] 模型輸出安全、提示詞注入、資料外洩與跨租戶測試有證據。

### 契約最低條款

- [ ] 只依書面指示；若指示違法立即通知。
- [ ] 保密、人員背景／訓練、最少權限、資料所有權與禁止留置。
- [ ] 子處理者同等義務；供應商對其行為負責。
- [ ] 事件通知：知悉後＿＿小時，且提供受影響資料、時間、範圍、措施與聯絡人。
- [ ] 跨境、政府要求、權利協助、證據保存、責任、保險、終止與移轉。
