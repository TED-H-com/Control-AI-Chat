# 法令遵循指南

這些指南協助組織自行評估如何使用 Control AI Chat，不表示軟體、功能或特定設定能使營運者符合法令。營運者仍須自行負責法律分析、組織面措施、技術控制、供應商安排及實際作業。

範本僅供作起點，使用前必須依營運者的實際情況調整，並交由法律顧問審閱。

## 選擇適用指南

先檢視組織設立、僱用或監督人員、提供服務、儲存或存取資料，以及向接收者傳送資料的所有國家，也要考量使用者、受影響個人、伺服器、管理員、關係企業、AI 供應商及其他受託者所在位置。同一部署可能同時適用多份指南；這三份指南也未必涵蓋所有適用法律。跨境活動另可能涉及產業、勞動、保密、紀錄保存、消費者、採購、出口管制或契約要求。

請先盤點事實，再選擇控制措施。法律適用及規範衝突應由合格律師判斷；不得假設只要遵循伺服器所在地的指南即已足夠。

## 回報錯誤

請透過 <https://github.com/TED-H-com/Control-AI-Chat> 的議題追蹤系統回報文件錯誤，並指出檔案、段落、陳述、資料截止日，以及佐證更正的官方第一手來源。請勿在公開議題中提供機密資訊、個資或安全性弱點。安全性弱點請依 [`SECURITY.zh-TW.md`](../../SECURITY.zh-TW.md) 通報。
