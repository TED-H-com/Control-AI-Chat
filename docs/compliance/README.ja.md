# コンプライアンスガイド

これらのガイドは、組織が Control AI Chat の利用を自ら評価するためのものです。ソフトウェア、機能または設定によって運用者が法令に適合することを示すものではありません。法的分析、組織的措置、技術的管理策、プロバイダーとの取決めおよび実際の運用については、運用者が責任を負います。

テンプレートは出発点にすぎません。利用前に運用者の事実関係に合わせて修正し、法律顧問の確認を受ける必要があります。

## ガイドの選び方

組織が設立され、人を雇用もしくは監督し、サービスを提供し、データを保存もしくはデータへアクセスし、または受領者へデータを送信するすべての国から検討を始めてください。利用者、影響を受ける個人、サーバー、管理者、グループ会社、AI プロバイダーおよびその他の委託先の所在地も考慮します。一つのデプロイに複数のガイドが適用されることがあり、この三つのガイドだけでは適用法をすべて網羅できない場合もあります。国境を越える活動には、業種、雇用、秘密保持、記録、消費者、調達、輸出管理または契約上の要件が別途適用されることもあります。

管理策を選ぶ前に、事実関係を整理してください。適用法と規則間の抵触は有資格の弁護士に確認し、サーバー所在地のガイドだけで足りるとは考えないでください。
